# Hotel Reservation System

## CodeAlpha Java Programming Internship - Task 3

A console-based Hotel Reservation System developed using Java as part of the CodeAlpha Java Programming Internship.

## Features

- View all hotel rooms
- Make a room reservation
- Store guest information
- Calculate total reservation cost
- View all reservations
- Cancel reservations
- Search available rooms
- Automatic reservation ID generation
- Menu-driven console interface

## Technologies Used

- Java
- ArrayList
- Scanner
- Object-Oriented Programming (OOP)
- VS Code

## Room Types

 Room Type  Price per Night 

 Single  1500 
 Double  2500
 Deluxe  4000
